# ReSOURCE Local Agent для Windows

Переносимая сборка не требует установки Python. Распакуйте весь ZIP в постоянную
папку, например `%LOCALAPPDATA%\ReSOURCE\Programs\LocalAgent`, и откройте
`ReSOURCE Local Agent.exe`. Рядом должна остаться папка `_internal`.
Программа не подписана цифровой подписью; сверяйте SHA-256 с каталогом CRM.

Настройки каждого профиля находятся в `%LOCALAPPDATA%\ReSOURCE\LocalAgent\profiles`.
Кнопка создания ещё одного профиля открывает отдельный экземпляр с независимыми
ключами, блокировкой и журналом. Обновление файлов программы не удаляет эти данные.
Закрытие окна оставляет приложение в области уведомлений; завершение — через
значок или вкладку настроек. Автозапуск включается только после отдельного согласия.

## Печать

Выберите Windows-принтер, проверьте его доступность без печати, создайте публичный
`registration.json`. Администратор вставляет его в CRM → Интеграции → Локальные
приложения → Добавить принтер. Включите обработчик в программе. Если принтеров
несколько, администратор явно назначает устройство для новых заданий.
Токен регистрации на сервер не передаётся: только UUID и SHA-256.

Текущий Print Agent продолжает работать. Для явного перехода на GUI штатно
остановите прежний агент, выберите его прежний config.json и включите печать здесь.
Программа использует прежние agent.lock и journal.sqlite3. Журнал не удалять:
он защищает от повторной печати. Неопределённый результат проверяется сотрудником
по бумаге; успешная отправка в Spooler ещё не означает выхода этикетки.

## Резервирование

Владелец создаёт ключ восстановления через настройки приложения. Приватный
`.recovery.pem` с паролем не передавайте CRM. Сделайте ещё одну отдельную копию
ключа, желательно на другом устройстве. Потеря единственного ключа/пароля делает
архивы непригодными. В CRM → Резервное копирование передаётся только `.public.pem`.
После сохранения ключа администратор задаёт расписание и включает функцию.

В CRM → Локальные приложения нажмите «Подключить устройство». В течение 10 минут
введите код в Local Agent. Ключ резервирования независим от ключа печати и не
расшифровывает архивы. Для замены получателя администратор явно подтверждает
замену: прежний ключ отзывается при подключении нового. Несколько принтеров
разрешены, а получатель полных архивов только один.

Выберите каталог, по умолчанию `%USERPROFILE%\ReSOURCE\Backups`, включите получение.
Расписание снимков хранится в CRM (03:00 Europe/Moscow по умолчанию); программа
получает готовые архивы, даже если во время снимка была выключена. Если CRM тоже
была выключена, пропуск честно отражается в журнале; новая копия имеет фактическое
время. Внеплановый запрос разрешается администратором при подключении устройства.

Загрузка идёт в `.partial`. После размера/SHA-256 выполняются атомарное переименование
и подтверждение CRM. При обрыве попытка продолжается для того же UUID/хеша.
Ошибка/нехватка места сохраняет прежнюю историю. Проверка в GUI проверяет SHA-256,
а не восстановимость БД. Проверку восстановления выполняйте отдельно по инструкции CRM.

Очистка выключена по умолчанию. При включении сохраняются 7 последних ежедневных
копий, дополнительные недели и срок можно настроить. Закреплённые, последняя
исправная копия, чужие файлы, ссылки и активные загрузки не удаляются автоматически.
После неудачной новой загрузки очистка не сокращает исправную историю.
Архивы на том же физическом диске не защищают от полного отказа диска.

Для удалённого сервера нужен HTTPS с действующим сертификатом. HTTP разрешён
только для localhost/127.0.0.1. Для другого сервера создайте новый профиль и явно
зарегистрируйте его; программа не отправляет старые токены другому origin.
