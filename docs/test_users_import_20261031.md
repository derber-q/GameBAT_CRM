# Перенос пользователей в тестовую CRM и перезапуск сайтов

Выполнено по прямому поручению пользователя 31.10.2026.

- Из основной SQLite, открытой в `mode=ro`, прочитаны только пользователи,
  принадлежность группам и права по естественным ключам permission.
- В `outputs/local_test/acceptance/test.sqlite3` созданы две учётные записи.
  Учебный `test-admin` сохранён; всего в тесте три пользователя.
- Сохранены логины, существующие хеши паролей, профили, активность и признаки
  staff/superuser; назначенные права проверены после импорта. У источника групп нет.
  ID тестовых пользователей назначены тестовой БД без перезаписи учебного аккаунта.
- Документы пользователей, сессии, ключи интеграций и бизнес-записи не переносились.
  JSON с профилями и хешами передавался дочернему процессу только через stdin,
  не сохранялся как файл и не выводился в журнал.
- Перед импортом создан согласованный снимок тестовой БД:
  `outputs/local_test/acceptance/backups/before_user_import_20261031_165928.sqlite3`.
  Проверки integrity/FK прошли; хеши всех таблиц вне пользователей/ролей совпали.
- Перезапущены только два сайта: рабочий 8000 и тестовый 8001. Рабочий запуск
  выполнен с `-SiteOnly -NoBrowser`, тестовый — для instance `acceptance` без
  повторной инициализации. Оба подтвердили HTTP-готовность.
- PID/время создания supervisor и четырёх worker сохранены (10 процессов с
  launcher). Мониторинг подтверждает 4 работающих сервиса, 0 неудач, аварий нет.
- Проверены loopback и LAN рабочего сайта, а также тестовый сайт. Только тест
  возвращает заголовок local_test и оранжевую метку.
- Браузерная проверка `python -m unittest core.local_test_browser_checks -v`:
  1 составной сценарий, `OK`, 3,735 с, код 0; вход учебным аккаунтом, мобильная
  навигация, отдельная сессия, оранжевая шапка и блокировка внешнего действия сохранены.
