# Добавление реализации в обычную продажу — 12.11.2026

Ручное добавление партий реализации в создание и редактирование продажи
разрешено только при типе `wholesale` и выбранном действующем Partner с
`platform_id`. Произвольное имя заказчика не заменяет связь с площадкой.
Партии выбираются по точному `stock_id`; их `platform_id` должен совпадать
с площадкой выбранного партнёра. Вознаграждения и партии не объединяются.

В `sales.views._consignment_options` включены только положительные остатки
площадок, связанных с действующими партнёрами. JSON содержит `partner_id` и
`platform_id`, но не себестоимость. `stock-lines.js` показывает кнопку добавления
и варианты только для текущего оптового партнёра. При смене партнёра или типа
продажи несовместимый выбор сбрасывается; строка остаётся для удаления/повторного
выбора. При ошибке выбора сохранять форму не даёт required-поле. Проданная до
нуля партия доступна только собственной уже существующей строке редактирования,
по её серверному снимку; новая строка такую партию не предлагает.

Backend независимо проверяет контекст в `quote_consignment_sale_lines` и при
списании в `consume_consignment_sale_lines`. Повторное чтение Partner под
блокировкой учитывает актуальную привязку. Ошибка создания или редактирования
откатывает всю транзакцию, включая восстановление старых партий. Обычные
складские/произвольные строки этого ограничения не получают.

У отчёта реализации сохраняется проверенный состав, но для создания оптовой
продажи по нему также нужен привязанный к площадке партнёр. Прежний отдельный
`record_consignment_sale` не является ручным добавлением в обычную продажу:
его фиксированная `consignment_platform` сверяется с каждой списываемой партией.
Исторические продажи, движения денег и товаров автоматически не изменяются.

Версия общей статики в шаблонах создания и редактирования — `20261112-1`.
Сценарии в `MixedConsignmentSaleTests`: смешанная оптовая продажа/отмена,
запрет розницы/Avito, произвольного партнёра и партнёра без площадки,
редактирование своей нулевой партии и откат при выборе чужого партнёра.
Тесты при внедрении не запускались по действующему указанию владельца.
