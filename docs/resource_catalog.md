# Каталог ReSOURCE: плотная сетка

3 октября 2026. Компоновка уточнена по мобильному референсу Wildberries; цвета, Manrope/Playfair и правила оптового заказа сохранены.

## Изменения

- На телефоне две колонки, боковые поля 10 px, промежуток 10 px. На desktop число колонок определяется доступной шириной (минимум карточки 200 px).
- Вертикальные фото 3:4 со скруглением, `overflow: hidden` и `object-fit: cover`. Рамки и фон отдельных карточек убраны.
- Порядок: оптовая цена → две строки названия → наличие → количество → широкая кнопка. Высота кнопок не меньше 44 px. Название полностью доступно на странице товара.
- Закрытый endpoint изображения создаёт WebP-кадр только при `crop=card`; оригинал не перезаписывается. В подробной карточке фото открывается целиком отдельной ссылкой.
- Индивидуальный фокус X/Y и масштаб 1–3 доступны в CRM: **Администрирование → Оптовая витрина → Кадрирование фото каталога**. Есть поиск товара и живой предпросмотр рядом с оригиналом. Сохранения через admin попадают в стандартный журнал администратора. Доступ ограничен правами модели и входом в admin.
- При замене титульного файла старое кадрирование перестаёт применяться до повторного сохранения настроек. По умолчанию фокус 50/50, масштаб 1. Универсальное дополнительное увеличение ко всем товарам не применяется.

## Фотографии

Проверены существующие горизонтальные оригиналы: NS2 Animal Crossing, зелёный DualSense, Nintendo Switch 2, PS VR2 PC Adapter, ASUS ROG Xbox Ally X и PS5 Дисковод. Для четырёх снимков сохранён индивидуальный фокус; увеличение 1,10 применяется только к проверенному снимку Animal Crossing. Остальные настройки масштаба — 1.

У очень широких коробок вертикальный кадр обрезает боковые края упаковки; весь оригинал доступен из подробной карточки. Содержимое фотографии не дорисовывается. Настройки позволяют переносить акцент на продаваемый предмет и убирать встроенные поля отдельно для конкретного файла.

Добавлена миграция `resource_storefront.0003_catalogimagecrop`, она создаёт отдельную таблицу настроек отображения. Перед применением сделана согласованная SQLite-копия `backups/crm_before_catalog_crop_20261003_161226.sqlite3`. Цены, остатки, фотографии и документы продаж не изменялись. Применённые четыре настройки перечислены в `outputs/resource-catalog/applied-framing.json`.
