## Источник количества и готовность

`source_snapshot` проверяет реальный рейс, подтверждённое `arrived_at` и наличие
всех заказов в `reviewed_orders`. Финансовая финализация не требуется.
Основной источник — положительный `TripCostRow.actual_quantity`. Нули остаются
в рейсе и не попадают в новую опись. Количество из заказанных строк, текущего
склада, Sale/Supply и первоначального количества не используется вместо факта.
Дополнительные позиции прежнего склада в продаже исключены по самой границе
источника: они не являются `TripCostRow`.

Покрытие источников перед сохранением сверяется по ID: каждый положительный
источник ровно один раз, без потерь и дублирования. Сумма исходных количеств
совпадает с фактическим составом. Количество документа — отдельное поле.
Отклонение требует права, явной отметки, причины и сохраняет сотрудника/время;
соответствующее событие содержит факт и заявленное значение. Источники не меняются.
Количество и клиентская сумма считаются целыми числами/BigInt, без float.

## Группировка и характеристики

Группа связана с конкретной Platform либо ProductType, имеет тип носителя и
подтверждённые поля. Точная настройка известных платформ создаётся отдельной
командой от имени администратора; по случайной подстроке товар не классифицируется.
Неизвестная платформа остаётся отдельной позицией для проверки. Техника остаётся
по моделям; одинаковая модель из разных заказов объединяется при совпадении
характеристик. Поставщики, заказчики и цены не являются ключом группировки.
Разные страны/материалы/изготовители/коды/маркировки/единицы разделяют строки.

Страна и материал: техника CHINA / МЕТАЛЛ / ПЛАСТИК; диски PS4/PS5
AUSTRIA / ПЛАСТИК; картриджи Switch/Switch 2 CHINA / ПЛАСТИК.
Единица ШТ, N пустое. Это начальные значения с предупреждением, а не
доказательство происхождения. Бренд техники предварителен, производитель игр
не угадывается. Код и маркировка без подтверждённого источника пустые.
Код проверяется только как 10 цифр, включая ведущие нули.

Русское имя приоритетно из снимка order_item, затем строки рейса, затем карточки;
у группы игр используется общее описание. Английский — подтверждённое значение
товара, затем группы, затем русское имя с отметкой о непроверенном переводе.
Внешних переводчиков и AI-запросов нет.

## Сохранение и независимость учёта

Семь новых моделей: `CustomsGroup`, `CustomsProductDefaults`, `CustomsManifest`,
`CustomsManifestLine`, `CustomsManifestSource`, `CustomsManifestExport`,
`CustomsEvent`. Одно сохранение — новая редакция с собственными строками,
источниками и автором. Файл экспортируется в защищённый FileField с UUID,
SHA-256, размером, хешем шаблона и предупреждениями, которые сотрудник подтвердил.
Связи со всеми исходными строками нормализованы. Исторические ID/названия/количества
сохранены дополнительно, SET_NULL не мешает допустимому пересозданию источников.

Сохранение документа не пишет в товары, рейс, прибытие, документы движения,
остатки, кассу и долги. Для согласованности используются транзакции/блокировки
рейса. Отдельные действия записи defaults требуют отдельного права и явного
подтверждения, обычное скачивание их не меняет. Приоритет: исправление описи,
подтверждённый товар, подтверждённая группа, общие правила, сведения CRM.

## Актуальность и история

Сохраняются ревизии рейса/прибытия, дата прибытия и отпечаток фактических строк,
платформ/типов/брендов, названий и сверенных заказов. Изменение источников
блокирует создание нового файла до обновления. Изменение общей таможенной
настройки не переписывает уже сохранённую редакцию: новое правило применяется
при явном обновлении.

Обновление переносит ручные поля только при однозначном взаимном сопоставлении
по группе и товарам, пересчитывает фактические количества, удаляет исчезнувшие
источники из новой редакции. Старые редакции остаются. При объединении/разделении
строк и новых товарах показана необходимость проверки. Ссылки истории открывают
прежнюю редакцию только для чтения, поэтому спорные исправления можно восстановить
после просмотра. Старая подтверждённая корректировка количества автоматически
не переносится на новый факт. Устаревший открытый редактор не перезаписывает
новую редакцию коллеги.
