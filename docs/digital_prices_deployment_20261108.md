# Включение цифрового каталога 08.11.2026

Владелец разрешил подключить предоставленный ключ API, применить миграции и
перезапустить рабочий контейнер, отдельно запретив запуск тестов.

## Сохранность данных

Все подключения к рабочей SQLite выполнены внутри `resource-crm-local`.
Windows Python к DB/WAL/SHM не подключался. До миграций создан снимок
`backups/pre_digital_prices_20261108_112154/database.sqlite3` через SQLite Backup API
из фиксированной транзакции чтения. Это включает согласованное состояние WAL.

Проверены integrity_check, foreign_key_check, восстановление в независимую SQLite
в памяти и совпадение количества строк всех 183 таблиц. Размер — 37 859 328 байт.
SHA-256, время и счётчики сохранены рядом в `metadata.json`; отдельно скопирован
файл ключа шифрования интеграций. Защищённый прежний снимок не изменялся.
Бизнес-записи, склад, продажи, долги и касса этой операцией не корректировались.

## Применённые изменения

План содержал только четыре новые миграции; все завершились с `OK`:

- `digital_prices.0001_digital_price_catalog`;
- `digital_prices.0002_initial_disabled_configuration`;
- `integrations.0014_digital_price_catalog`;
- `telegram_bots.0003_digital_price_catalog`.

Ключ прочитан из предоставленного владельцем локального файла и передан процессу
через stdin, без включения значения в командную строку, журналы или исходники.
Настройка сохранена штатным `save_configuration` с шифрованием и аудитом.
Интеграция включена; ежедневное расписание оставлено выключенным, поскольку
владелец не назначил время. Через `enqueue_sync` создано первое ручное задание.

Контейнер перезапущен штатным Docker restart. Использован прежний образ с уже
установленными зависимостями и bind mount исходников; пересборка не требовалась.

Telegram-сообщения ради проверки не отправлялись.

## Как открыть

В CRM: **Ценообразование → Цифровые товары**,
`http://127.0.0.1:8000/crm/pricing/digital/`.
На странице доступны наценки, ручное обновление, предпросмотр, скачивание и
настройки API. Для сотрудников используются отдельные permissions нового приложения.
В CRM-боте сотрудников — `/start`, затем **Прайс цифровых товаров** при наличии
права скачивания. Уже показанная Telegram-клавиатура обновляется при обращении к меню.

Тестовые suites не запускались по прямому указанию владельца. Это протокол
ввода и проверки рабочего состояния, а не подтверждение прохождения тестов.
Исторический отчёт подготовки от 07.11.2026 сохранён как описание того этапа.
