# Доплаты за постоплату закупочного прайса

Правила взяты из файла «Модель наценки за постоплату для tech.txt» и уточнений пользователя от 13.10.2026. Все суммы — RUB за единицу товара.

Для CD по умолчанию действует ступенчатая доплата: 60 ₽ при предоплате менее 2000 ₽, 80 ₽ от 2000 до 2999,99 ₽, 100 ₽ от 3000 ₽.

Специальная ставка важнее общей: например, панели PS5 Pro стоят 200 ₽, хотя консоль PS5 Pro — 1000 ₽. Наушники Nintendo стоят 200 ₽, а не 100 ₽ за прочую периферию. Meta Quest Elite Strap считается VR-аксессуаром даже при ошибочном типе «VR-шлем» в старой карточке.

На странице версии после постоплаты находится поле «Доплата за постоплату, RUB». При его изменении предоплата и наценка сохраняются, а постоплата пересчитывается. Ввод постоплаты, наоборот, определяет предоплату и наценку с учётом этой доплаты. Для изменения требуется право изменения наценки закупочного прайса. Доплата должна быть неотрицательной; допустим 0.

Нажмите «Сохранить расчёт», чтобы запомнить изменённую доплату за конкретным товаром. Следующие версии используют её вместе с сохранённой наценкой. Для CD ручное изменение доплаты также фиксирует сумму вместо ступенчатого расчёта. Неизменённая ставка старого снимка автоматически не становится ручным правилом для новых версий.

Для нового типа или модели без согласованной ставки программа перед созданием прайса запрашивает доплату в отдельной таблице. Она сохраняется только при успешной генерации, в одной транзакции с прайсом и недостающим весом. Старая дисковая доплата автоматически к неизвестной технике не применяется.

Новые правила применяются при создании новых версий. Для старых строк Tech без фиксированной ставки в ещё не использованном прайсе предусмотрена согласованная коррекция командой `backfill_procurement_tech_surcharges`: она задаёт ставки из таблицы и пересчитывает только постоплату. Предоплата, наценка, доставка, строки CD и товарная память не меняются. Уже заданные фиксированные доплаты сохраняются. Прайсы, использованные в клиентских заказах, защищены от такой коррекции; снимки заказов не меняются. Доплату редактируемого прайса по-прежнему можно изменить вручную.
