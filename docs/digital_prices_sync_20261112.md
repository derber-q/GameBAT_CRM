# Обновление цифровой себестоимости 12.11.2026

Диагностика выполнялась внутри Docker и только GET-запросами к существующим
источникам. Последние две задачи завершились `network` после пяти попыток.
Проверка `/api/external/v2/products?page=1` показала ответ 200 за 30,5 секунды:
прежний read timeout 25 секунд обрывал исправный, но медленный ответ поставщика.
Каталог кодов v1 и Google Sheets отвечали отдельно без ошибки авторизации.
Официальная документация `https://yanstore.ru/api-docs-v2.html`, прочитанная
прямым HTTPS GET, сохраняет тот же контракт страниц по 50 товаров.

`CatalogClient` использует `(5, 75)` только для каталога товаров v2. Время одной
попытки ограничено и короче аренды SyncJob (120 секунд); heartbeat обновляет
аренду перед страницами. Новая категория `network_timeout` отличает ожидание
ответа от прочего сетевого сбоя, штатная очередь повторяет запрос по старому
правилу (до пяти попыток, минимум через минуту). Скрытых повторов HTTP нет.
Ключи не печатаются, не передаются на новые домены; TLS и redirects не ослаблены.

В текущей таблице поставщика «Игры СНГ» содержит `1–99`, `100–349`, `350–999`,
`1000–1999`, `2000+`, всего пять диапазонов. Старый каталог CRM содержал ещё
`2000–2999`, `3000–3999`, `4000+` вместо единого верхнего диапазона.
Разбор `sheet_source` уже корректно считывает новую таблицу (41 тариф), но
старое сопоставление по точному диапазону отклоняло ручную часть обновления.

`sheet_structure.reconcile_sng` внутри транзакции `apply_catalog` принимает
только этот подтверждённый переход. Проверяются весь будущий состав и ревизии
затрагиваемых строк до изменений. Строка `2000–2999` становится `2000+` с тем же
ID, общими и индивидуальными наценками. `3000–3999` и `4000+` сохраняются с новым
`source_archived=True`; они не входят в актуальные таблицы, редактор и PNG,
но их себестоимость, настройки, ссылки и прежние документы не удаляются.
Старые вкладки не могут сохранять архивные строки. В аудит добавляется событие
`sheet_structure`. Наценки и режим расчёта не меняются при обновлении стоимости.

Неизвестная перестройка источника не принимается автоматически. При изменении
строки сотрудником во время чтения Sheets переход не выполняется; API-снимок
при этом может обновиться отдельно, как и прежде. Пустая стоимость не затирает
предыдущую, нулевое наличие API сохраняет статус «Нет в наличии».

Миграция `digital_prices.0011_archived_source_tariffs` добавляет только признак
архива, без изменения рабочих строк. Переход и новые цены применяются при
успешном штатном обновлении. Перед рабочей миграцией требуется согласованная
SQLite-копия с проверкой восстановления. Тестовые сценарии подготовлены в
`digital_prices/test_sheet_structure.py`, но не запускаются без команды владельца.
