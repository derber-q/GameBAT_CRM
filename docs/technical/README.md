Справочники воспроизводятся из текущего дерева:

```powershell
.venv\Scripts\python.exe scripts/build_technical_reference.py
.venv\Scripts\python.exe scripts/build_technical_reference.py --check
```

Команда читает исходники и Django metadata. Она не выгружает строки рабочей БД, не запускает миграции, фоновые процессы или внешний API. Ссылки с номером строки относятся к моменту генерации.

## Приоритет и актуальность

Цель задаёт текущее поручение пользователя, правила работы — `AGENTS.md`, реализованное поведение — текущие модели/сервисы/views/forms/URL/templates/tests. Документы следует сверять с кодом. Исторический отчёт содержит доказательства для своей даты, а не результат сегодняшнего запуска.

В частности, ранний сценарий создания операций рейса с отдельным вводом курсов заменён общим прибытием и финализацией. Действующий тематический контракт — [прибытие рейса](../trip_arrival_costs.md). Продажные цены складского прихода подтверждаются после общей финализации по будущей средней себестоимости физического остатка.

## Граница этой подготовки

Очистка не переписывает опубликованную Git-историю и не меняет алгоритмы складского/денежного учёта. Удалены только подтверждённо ненужные источники/артефакты. Документирующие Python-изменения сверяются с исходным AST после исключения docstring; изменение состояния базы или внешних площадок не используется как тест.

Итог проверок и фактический объём очистки: [отчёт подготовки](../maintenance_20261031.md).
