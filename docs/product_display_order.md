# Порядок товаров в таблицах CRM

На страницах «Общие остатки», конкретного склада, «Номенклатура» и «Ценообразование» техника отображается перед CD. Техника сгруппирована по бренду, внутри бренда — по типу; оба уровня можно свернуть независимо.

Общие правила находятся в `catalog/product_ordering.py`. Генератор оптового и розничного Excel-прайса использует этот ключ с параметром `for_excel=True` для дополнительных правил Excel.

- Сначала Sony, затем Nintendo, бренды портативных консолей и прочая техника.
- Sony: игровая консоль, внешний привод, зарядная станция, геймпад, зарядная станция для геймпадов, запасная часть, игровая гарнитура, VR-шлем, VR-аксессуар, стриминговая приставка. Станции для геймпадов идут после геймпадов и в CRM, и в Excel.
- Nintendo: портативная консоль, чехол, геймпад, игровая гарнитура.
- Типы без специального приоритета идут после известных типов по названию. Для портативной и прочей техники применяется существующий порядок прайса.
- Внутри типа товары сортируются по названию. Для геймпадов Sony сохраняются приоритеты моделей и цветов из `price/sony_gamepad_sorting.py`.
- Только в Excel все DualSense Edge идут перед остальными геймпадами Sony. Порядок геймпадов в CRM сохраняется.
- Только в Excel VR-шлемы других брендов образуют раздел `Tech · VR-шлемы · <бренд>` после портативных консолей, перед прочими товарами. VR-шлемы Sony остаются в Sony; VR-аксессуары других брендов остаются в прочих товарах.
- CD идут по платформам и названиям. В «Номенклатуре» сохранена дополнительная группировка по игровой серии.

У бренда, чьи товары относятся одновременно к портативной и прочей технике, одна группа: её положение определяется первым товаром в порядке прайса. Все строки сохраняются ровно один раз. В остальных брендах применяется тот же принцип; в Excel прочая техника остаётся общим разделом.

Группировка выполняется после проверок доступа, фильтрации и правил наличия конкретной страницы. Остатки и цены не пересчитываются. Сохранение цен через AJAX и редактирование мест хранения используют существующие формы.

Проверки: `catalog.test_product_ordering`, `catalog.test_product_browsing`, `catalog.browser_product_ordering`; снимки браузерной проверки сохраняются в `outputs/product-ordering/`. Браузерный сценарий работает с отдельной тестовой базой.
