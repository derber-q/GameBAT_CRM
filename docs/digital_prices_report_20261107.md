# Отчёт подготовки цифрового каталога — 07.11.2026

## Исходное состояние

Ветка `main`, исходный HEAD `51321a03ba50b77f8dd19cf7f5ae3878bb7301f5`.
Рабочее дерево изначально содержало многочисленные изменения и новые приложения
digital_sales/wholesale_bot, миграции и доработки финансов. Они сохранены.
Новый пакет добавлен поверх текущих исходников. Commit, push, reset и clean не выполнялись.

Прямое указание владельца: **не применять миграции, не перезапускать CRM,
не трогать рабочую базу до отдельной команды**. В рамках этого пакета не было
Docker start/stop/restart/exec, migrate, запуска worker, чтения рабочего API-ключа,
записей в рабочую БД или отправок Telegram. Исследование ограничено публичной
документацией и файловыми исходниками. Для check/создания файлов миграций выбран
local_test с `:memory:`, без унаследованных секретов; это не рабочий сайт.

## Что подготовлено

1. Новый `digital_prices`: модели каталога, ручные параметры, редакции, аудит,
   очередь обновлений, защищённые комплекты PNG и постраничная доставка.
2. API-клиент по подтверждённому контракту GET products, X-Api-Key, page/has_more,
   amount Decimal, доступность available, currency. Покупок через API нет.
3. Атомарный импорт после полной загрузки, сохранение наценок и переименований,
   отсутствие удаления исчезнувших строк, ошибки и ограниченные повторы.
4. Два округления, nullable-наценка и «Цена уточняется», отсутствие выдуманных
   валютных пересчётов. Месячный срок Spotify/ChatGPT не включает округление 50 ₽.
5. Раздел «Ценообразование → Цифровые товары»: фильтры, AJAX, конфликт редакции,
   настройка оформления и интеграции, реальные PNG в предпросмотре, ZIP всего комплекта.
6. Отдельные permissions; строковые DTO и PublicCatalog не передают закупку
   пользователю без права/в рендерер/Telegram. Файлы не вынесены в публичные media.
7. Pillow-рендерер с локальным шрифтом, карточками/флагами, читаемой пагинацией,
   недоступными и неизвестными строками. Синтетические изображения просмотрены визуально.
8. «Прайс цифровых товаров» в существующем боте: одна кнопка, без выбора категорий,
   свежая авторизация на каждом этапе, sendPhoto, PageDelivery, partial/uncertain.
9. Новый наблюдаемый worker в прежнем supervisor и Windows/Linux-адаптерах.
   Время ежедневного обновления настраивается, по умолчанию не задано.

Подробная схема, методы, правила, файлы и запуск: [digital_prices.md](digital_prices.md).

## Что подтверждено и что отложено

Документация [YanStore v2](https://yanstore.ru/api-docs-v2.html) получена HTTPS GET.
Подтверждены URL/заголовок, схема offers/page/has_more, валюта на каждой позиции,
available и различие ps/xbox от game/xbox_game/code. Примеры документации
не загружались в рабочий каталог и не выдаются за цены магазина.

Живой API с ключом владельца не вызывался. Не подтверждены доступные категории,
валюта магазина и реальное количество предложений. Ключ нужен при будущей настройке.
Игры, доступные только через search, нельзя перечислить целиком документированным
products; их универсальная выгрузка не объявлена реализованной. Google Sheets
и личная переписка поставщика не используются как скрытая замена API.

Оригинальные два PNG-референса в доступных файлах не найдены. Вид основан на
текстовом описании; точное визуальное совпадение не подтверждено. Для него нужны
исходные изображения и при необходимости фирменный логотип/разрешённые значки.
В текущей графике только текст GameBAT, локальный шрифт и геометрические флаги,
без поставщика и без ReSOURCE как клиентского бренда.
